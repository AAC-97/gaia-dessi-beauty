# Gaia Dessi Beauty

Sito statico autonomo per Gaia Dessi Beauty, pronto per un repository separato e dominio dedicato.

## Dominio configurato

Dominio provvisorio scelto: `gaiadessibeauty.it`.

Se il dominio definitivo cambia, sostituire `gaiadessibeauty.it` in:

- `CNAME`
- `index.html`
- `robots.txt`
- `sitemap.xml`

## Da configurare prima del go-live

- Comprare o collegare il dominio definitivo.
- Collegare endpoint Formspree reale nel form contatti.
- Verificare privacy policy definitiva.
- Pubblicare il sito in un repository GitHub separato.
- In GitHub Pages, configurare il custom domain e attendere il certificato HTTPS.
